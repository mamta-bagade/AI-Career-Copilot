# AI-Career-Copilot
AI-powered resume analyzer built with Flask, Groq AI (Llama 3.1), and TiDB. Features skill gap analysis, roadmap generation, interview questions, and secure authentication with OTP-based password reset.

## 🔗 Live Demo
👉 https://ai-career-copilot-r5ff.onrender.com

## 🚀 Features
- 📄 Resume upload (PDF/DOCX) or paste text
- 🤖 AI-powered skill gap analysis using Groq (Llama 3.1)
- 🗺️ Personalized learning roadmap generation
- 🎯 Interview questions based on target role
- 🔐 Secure authentication with password hashing
- 📧 Forgot password with Gmail OTP verification
- 📊 Analysis history tracking

## 🛠️ Tech Stack
- Backend: Python, Flask
- AI: Groq API (Llama 3.1 - Free)
- Database: TiDB Cloud (MySQL)
- ORM: SQLAlchemy
- Frontend: HTML, CSS, Jinja2
- Deployment: Render.com
